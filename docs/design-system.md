# Design System - Cell'EX

## Tema Visual
**'Dark Tech Minimalist' / Terminal & Code Vibe**

## Palet Warna
| Nama | Hex | Keterangan |
|------|-----|------------|
| Background Utama | `#0A0A0A` | Hitam pekat |
| Warna Teks | `#F3F4F6` | Putih Tulang |
| Aksen Interaktif | `#10B981` | Electric Emerald |
| Warna Permukaan/Hover | `#171717` | Dark Grey |

**DILARANG** menggunakan gradien ungu, biru corporate, atau warna-warna template AI standar.

## Tipografi
| Elemen | Font | Catatan |
|--------|------|---------|
| Heading / Logo | **Space Mono** atau **JetBrains Mono** (Monospace) | Memperkuat kesan coding/tech |
| Body / Paragraf | **Inter** atau **Geist** (Sans-serif) | Bobot tipis/reguler, bersih |

## Bentuk UI
- **Hindari** `border-radius` besar (`rounded-xl`, `rounded-full`)
- Gunakan **sudut tajam** atau **membulat sangat halus** (`rounded-sm` atau sharp edges)
- Agar terasa **tegas dan modular**
