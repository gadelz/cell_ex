# Project Brief - Cell'EX

## Nama Proyek
Cell'EX (cell_exchange)

## Tujuan
Membangun web profil dan direktori pemesanan untuk layanan teknis dan digital.

## Target Utama
Estetika web yang **tidak terlihat seperti template e-commerce generik buatan AI**. Fokus pada:
- Performa ringan
- Alur pemesanan tanpa hambatan (langsung ke WhatsApp)
- Micro-interactions yang mulus
